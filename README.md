# QGIS Batch Chainage Extraction

Projects survey points onto road centerlines and gives you chainage values. Built for civil engineers who don't want to do this manually.

```
run.bat → select project folder → done
```

Output goes to `output_chainage/{project_name}/chainage_results.csv`

Tested on NH01 and NH02 highway projects. Default CRS: UTM 45N (EPSG:32645).

Requires QGIS LTR 3.44+ at C:\OSGeo4W (Windows).
